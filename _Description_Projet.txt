Projet = FrenchJumper Bot

Dernière mise à jour : 28/09/2026


BUT DU PROJET

Le projet FrenchJumper Bot fournit les fonctions Discord propres à la communauté
FrenchJumper.

Il s'agit d'un bot distinct de PathFinder XIII :
- application Discord différente ;
- serveur Discord différent ;
- Worker Cloudflare différent ;
- secrets et configuration séparés ;
- aucune dépendance technique entre les deux bots.

Le service est hébergé exclusivement sur Cloudflare, sans dépendance à
l'ancienne plateforme d'hébergement.

FONCTIONNEMENT ACTUEL

Le bot fonctionne comme un service HTTP Cloudflare Workers utilisant l'API REST
officielle de Discord.

Il ne maintient pas de connexion permanente au Discord Gateway. Cette
architecture évite d'avoir un serveur Node.js actif en permanence et reste
compatible avec l'offre gratuite de Cloudflare.

Fonctions disponibles :

- GET /health
  Vérifie que le Worker répond correctement.

- GET /health/discord
  Vérifie de manière protégée que le token Discord correspond bien au bot
  FrenchJumper. Cette route ne modifie rien sur Discord.

- POST /sync
  Permet à une application autorisée de modifier le surnom d'un membre et
  d'ajouter ou retirer ses rôles Discord.

- POST /webhooks/entropia-central
  Reçoit les notifications signées d'Entropia Central et les enregistre de
  manière idempotente dans la base D1. Un même événement reçu plusieurs fois
  n'est pas traité plusieurs fois.


SECURITE ET SECRETS

Les secrets sont configurés exclusivement dans Cloudflare :

- BOT_TOKEN
  Token officiel de l'application Discord FrenchJumper Bot.

- SYNC_TOKEN
  Clé privée utilisée par les applications autorisées pour appeler POST /sync.

- ENTROPIA_CENTRAL_SIGNING_SECRET
  Secret facultatif servant à contrôler la signature HMAC des notifications
  Entropia Central.

Variable non secrète :

- ALLOWED_GUILD_IDS = 442710603300208652
  Limite les opérations Discord au serveur FrenchJumper autorisé.

Les fichiers .env et .dev.vars sont ignorés par Git et ne doivent jamais être
publiés.


BASE DE DONNEES D1

La base D1 frenchjumper-bot conserve :

- les livraisons reçues depuis Entropia Central ;
- leur état de traitement ;
- les informations nécessaires à l'anti-doublon ;
- les paramètres globaux prévus par le module Entropia.

La structure initiale est versionnée dans :
migrations/0001_initial.sql


CE QUE LE BOT NE FAIT PAS ACTUELLEMENT

- Il ne se connecte pas en self-bot avec un compte utilisateur Discord.
- Il ne contient aucun token utilisateur.
- Il ne scrape pas Discord.
- Il ne peut pas lire librement un salon situé sur un serveur distant où
  l'application FrenchJumper Bot n'est pas installée et autorisée.

Le lecteur périodique Entropia Central est actif, avec un Cron chaque minute
depuis le 28/09/2026 (r.22). La destination est pilotée par le dashboard ; la bascule de salon a
été confirmée par l'utilisateur (r.16).

Pour relayer un salon Discord ordinaire, le bot doit être installé sur le
serveur source avec les permissions nécessaires. Si cela n'est pas possible,
la solution recommandée reste un flux RSS, une API officielle ou un webhook
fourni par la source.


EVOLUTION PREVUE : LECTEUR DE NEWS

Une extension gratuite et facilement délégable peut être ajoutée au Worker :

- déclenchement périodique avec Cloudflare Cron Triggers ;
- lecture d'un ou plusieurs flux RSS ou API officielles ;
- stockage dans D1 de l'identifiant ou de l'URL des publications déjà traitées ;
- prévention automatique des doublons ;
- publication dans un salon Discord par webhook ou API REST ;
- journalisation des succès et erreurs dans Cloudflare ;
- configuration des sources et salons sans modifier les secrets du bot.

Cette évolution ne nécessite ni hébergeur supplémentaire, ni serveur permanent, ni self-bot.


MODULE ENTROPIA CENTRAL EN VALIDATION

Le Worker contient désormais un lecteur autonome des globals Entropia Central.
Il ne dépend pas des comptes Entropia Central individuels des membres.

Fonctionnement développé :

- chargement de la liste officielle depuis l'API du projet Membres ;
- sélection des membres actifs avec niveau strictement supérieur à zéro ;
- rafraîchissement du roster toutes les six heures ;
- lecture paginée de l'API publique Entropia Central ;
- reprise depuis un curseur persistant avec chevauchement de sécurité ;
- comparaison normalisée des noms d'avatars ;
- inclusion des équipes dont le nom contient Frenchjumper ou FRJ, sans distinction de casse ;
- stockage D1 des seuls globals FrenchJumper ;
- anti-doublon fondé sur l'identifiant du global Entropia Central ;
- publication par FrenchJumper Bot dans un salon Discord configurable ;
- cinq tentatives avec délai progressif en cas d'échec Discord ;
- statut protégé accessible sur GET /health/entropia ;
- déclenchement manuel protégé sur POST /admin/entropia/poll.

Mode de transition retenu :

- les notifications Entropia Central actuelles, configurées membre par membre,
  continuent de publier dans le salon Discord existant ;
- le nouveau lecteur publiera dans un salon privé temporaire ;
- les deux résultats seront comparés avant la bascule définitive ;
- le changement de destination final nécessitera seulement le remplacement de
  l'identifiant du salon Discord.
